# 功能列表

功能按宿主分组路由。以下是主要功能清单（版本持续更新，以 App 内实际开关为准）。

## 系统框架（system_server / framework）

| 功能               | 说明                      |
|------------------|-------------------------|
| 音量阶数             | 自定义音量级数                 |
| 移除状态栏顶部警告        | 隐藏「正在显示屏幕内容」等常驻提示       |
| 移除 VPN 激活通知      | 隐藏 VPN 常驻通知             |
| 应用分身限制           | 自定义多开应用数量/黑名单           |
| USB 安装确认         | ADB/USB 安装免确认           |
| 移除 72 小时密码验证     | 免模式锁定期验证                |
| 强制所有应用分屏         | Android 13 及以下强制分屏      |
| 遮罩 Splash Screen | 快速启动无闪屏                 |
| 不受信任的触摸          | 允许重复触摸注入                |
| 暗色模式服务           | 第三方应用强制暗色列表             |
| 电池优化白名单          | 防止后台杀进程                 |
| LTPO 动态刷新率       | 自定义刷新率策略                |
| 音量键控制手电筒         | 熄屏长按音量键开关手电             |
| 移除卸载黑名单          | 取消内置应用卸载限制              |
| 强制 32 位支持        | Android 13+ 允许安装 32 位应用 |
| GMS 限制           | 移除 Google 服务使用限制        |
| 应用保活             | App 停止时保持通知常驻           |
| 风险应用拦截           | 关闭系统风险应用检测              |

## SystemUI / 状态栏 / 锁屏

| 功能      | 说明                 |
|---------|--------------------|
| 状态栏时钟   | 样式/字体/对齐/秒显示       |
| 状态栏网速   | 上行下行布局与字体          |
| 状态栏图标   | 蓝牙/WiFi/信号/电池图标显隐  |
| 控制中心    | 磁贴列数/时钟日期样式/背景透明度  |
| 通知样式    | 全局简约横幅/两端对齐/背景透明模糊 |
| 锁屏时钟    | 时钟与冒号样式、双时钟        |
| 锁屏充电组件  | 充电样式/瓦数/技术显示       |
| 锁屏底部按钮  | 手电筒/相机替换与移除        |
| 锁屏运营商   | 自定义运营商与显隐          |
| 指纹图标    | 移除按压动画、替换自定义图标     |
| 音量对话框   | 背景透明度/百分比显示        |
| 充电纹波    | 息屏充电动效             |
| 电源菜单    | 手动锁定按钮 / 移除 SOS    |
| 移除各类对话框 | USB/低电量/录音/投屏提示    |

## 设置与系统应用

覆盖设置、相册、相机、主题商店、云服务、游戏助手、应用增强服务、软件更新、浏览器、日历、天气、智能侧边栏、手机管家、支付保护、录音、健康、NFC、互传、文件管理、工程模式等，例如：

- 设置：DPI 免重启、暗色模式列表、应用专属语言、Google 自动填充、停用系统应用、设备分享参数、OTA 卡片背景
- 相机：Debug UI 选项、自定义机型水印、移除水印字数限制
- 相册：移除 AIGC 消除限制、自定义水印
- 游戏助手：开发者入口、X 模式、弹幕白名单、移除 Root 检测
