# 常见问题

## 模块不生效

1. 确认 LSPosed 中模块已启用、目标 App 在作用域内
2. 确认没有 `/sdcard/disable_lt` 残留文件
3. 查看 LSPosed 日志中是否出现 LuckyTool 在宿主进程的加载记录；若没有说明未注入
4. 重启设备后重试（部分系统进程仅冷启动注入）

## 提示「不支持的 Xposed 环境」

模块启动时未检测到已绑定的框架服务（未激活 / 无框架 / 等待超时）：

- 先在 LSPosed 启用模块并选中作用域，再打开模块 App

## 部分功能开关无效

- 功能按 **ColorOS 版本分支**实现，系统大版本升级后需等模块适配
- App 内未出现该开关的版本表示当前版本尚不支持

## 更新系统后功能全失效

系统更新会替换系统应用（内部类名/方法名变化）。请更新到最新版模块，若仍失效请反馈，附带系统版本与模块日志。

## 图标 / 动画类功能异常

指纹图标、状态栏图标等系统界面功能在新版 SystemUI
上链路变化大，请使用最新版模块并反馈具体现象（显示不全 / 颜色异常 / 动画不启停等），便于针对性适配。

## Root 相关

- 部分需要写系统分区的功能（高刷、DC 调光等）需要 Root 与权限授权
