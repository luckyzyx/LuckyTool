# 安装与激活

## 1. 安装模块

1. 下载最新版 `LuckyTool_v*.apk`
2. 正常安装 APK（模块 App 本体）

## 2. 激活模块

1. 打开 LSPosed 管理器 → **模块** → 找到 LuckyTool 并启用
2. 在「作用域」中选择需要 Hook 的系统应用（推荐全部勾选，模块对每个包会自适应跳过不适用逻辑）
3. 重启设备（或至少重启对应作用域）

## 3. 开启总开关

- 首次进入模块会检查适配状态（Root 权限 / 作用域配置）
- 打开 LuckyTool 主页右上角「模块开关」

::: tip 应急开关
在内部存储根目录 `/sdcard/` 下创建空文件 `disable_lt` 可以**全局禁用**模块的所有功能，用于排查问题时快速退出。
:::

## 4. 验证生效

- 在 LSPosed 管理器 → 日志中能看到各系统进程的 LuckyTool 加载日志，即代表注入成功
- 打开任一功能开关，观察对应系统界面变化

## 注意事项

- 部分功能依赖 Root 权限（写系统分区 / 执行内核命令），检查模块内权限页
- 作用域未包含目标应用时，该应用相关功能不会生效
- 系统大版本升级后部分功能可能暂时失效（等模块适配新版本）
- 指纹图标、状态栏图标等 UI 功能在新版 SystemUI 上变化较大，异常时优先升级模块版本
