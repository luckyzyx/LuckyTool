# 锁屏凭据快捷入口

## 集成决定（2026-10-30）

锁屏页面通过 `ScopePageSpec.restartEnabled` 和 `FunctionPage` 接入 `RestartMenuUtils.RestartScopeDialog`。该菜单负责作用域重启；快捷入口的设置项只保存和通知偏好，不添加独立重启命令。开启后通过原有菜单重启作用域，已经装载的功能可通过偏好通知关闭。

保留 `CredentialHookBridge` 的直接 libxposed 注册。检查本机 YukiHook 1.5.0 依赖字节码发现：`MemberHooker.hook` 捕获注册异常并记录日志，`Handle.onHooked` 和 `onHookingFailure` 不执行传入回调。仅拿到高层句柄不能证明整组钩子注册成功。凭据入口必须在钩子就绪后才限制原生上滑，当前桥接通过实际注册返回值维护句柄数，并在失败时回退。

保留原生钩子存在时拒绝热重载的保护。按钮 drawable、监听器和宿主模型持有本代模块对象，仅自动解除旧钩子不足以安全迁移这些引用。此功能使用作用域重启生效；热重载迁移需要单独实现宿主状态清理、恢复及完整包实机验证。

## 验证

同步上游后 Wrapper 升至 Gradle 9.8.2，首次下载触发 10 秒超时；此失败发生在源码编译之前。官方分发包传输过慢，停止本会话的 Wrapper 下载，使用本机已缓存的 Gradle 9.8.0 验证，仓库 Wrapper 配置保持 9.8.2。脚本支持通过 `CREDENTIAL_GRADLE` 指定现有可执行文件。

AGP 9.5.0 尚未缓存，Gradle 请求 Google Maven 的 TLS 握手失败，Maven Central 请求返回 403。兼容验证暂用已缓存的 AGP 9.4.1，完成后恢复上游 9.5.0 配置，不将旧工具链结果标成新工具链通过。

运行 `sh scripts/check-credential-shortcut.sh --build`，执行锁屏相关测试并构建完整 debug APK。脚本保存和恢复 Gradle 配置阶段自动修改的 `app/version.properties`，避免验证改变待提交版本号。

测试涵盖凭据入口、Hook 回调失败恢复、触摸流分发、图标绘制、原生缩放与释放参数、设置页面。资格检查优化必须缓存访问成员而非实时资格值；用户切换、锁定状态和生物识别策略变化必须在后续检查中生效。

本轮手机已离线，不执行设备安装或重启。现有 PR 曾记录独立模块的图案锁验证，但仓库没有对应原始实机记录，不能据此声称本轮完整包已通过设备验证。完整包的图案、PIN、密码、无镜像动画、偏好关闭恢复及原生菜单重启仍需实机验收。

## 审查改进

上一轮审查把单测通过推导成没有崩溃或误解锁风险，结论超出证据。后续审查区分静态发现、单测覆盖、完整包构建与设备运行；检查测试是否仍连接生产路径，清理仅测试已弃用策略的用例。

PR 面向维护者完整说明功能、行为条件和已通过的检查。设备覆盖缺口记录在开发笔记中，不以「本轮」等会话过程措辞组织 PR，也不把未执行的验证列为通过。

删除通知命中检测前已核对其结果只供日志使用。通知子视图事件、四入口分发、空白上滑取消与 `downTime` 改写的行为测试保留；合成取消事件仍使用实际保存的原生按下事件时间。入口尚未就绪时先返回，避免无意义的指纹资格查询。

桥接测试原先仅覆盖业务回调抛错，没有覆盖失败处理器再次抛错。`reportFailure` 现在隔离恢复/日志处理器的异常，避免它覆盖原生结果或阻断钩子释放；新增测试覆盖 before/after 与失败处理器同时失败时的原生返回和异常传播。

原生凭据页暂时拒绝显示时不再永久禁用快捷入口；仅入口结构已经失效才禁用。请求拒绝后清除手势去重标记，允许后续重试。

不要修改正在执行的 shell 脚本：shell 可能逐段读取文件，运行中插入注释也会改变续读位置。首次兼容构建与 88 项测试通过后，因修改运行中的脚本出现尾部解析错误；冻结脚本后再验证最终退出状态。

最终生产代码通过 Gradle 9.8.0／AGP 9.4.1 的完整 debug APK 构建及 88 项相关测试（11 类，0 失败、0 跳过）。脚本重新运行正常退出并恢复版本文件。APK 中模块入口为 `com.luckyzyx.luckytool.hook.Entry`，API 102，包含 SystemUI 作用域。

随后仅修改测试辅助函数的可空断言，增量编译发现 KSP 输出目录出现 `Entry 2.kt` 等重复生成文件；重复报告也使统计数量翻倍。核对副本内容后清理重复生成产物，测试统计只认标准 `TEST-<class>.xml`，不计带数字副本的历史报告。
